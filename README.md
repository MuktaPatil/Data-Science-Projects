## Projects
## Federal Aviation Authority Dataset Analysis
Type: Exploratory Data Analysis <br>
Tech: Python, Pandas, Matplotlib <br>
Analysis of FAA dataset to uncover patterns in aviation incidents and safety trends.<br>

## 📈 Firm Sales Predictions
Type: Regression <br>
Tech: Python, Scikit-learn, Linear Regression <br>
Predicts firm sales based on advertising spend across TV, Radio, and Newspaper channels. A Linear Regression model is trained on 75% of the data and evaluated on the remaining 25%.<br>
### Results:

* MSE: 1.40 <br>
* Coefficients: 0.003 (Newspaper), 0.179 (Radio), 0.047 (TV)


## 🚢 Titanic Survival Prediction
Type: Binary Classification<br>
Tech: Python, Scikit-learn, Logistic Regression <br>
Predicts passenger survival on the Titanic using logistic regression. Features include passenger class, age, sex, and embarkation point. <br>
